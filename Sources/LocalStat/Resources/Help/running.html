Running and diagnostics

Run Program executes the entire current buffer in a fresh local process. Selected text is not run separately. WORK datasets and macro definitions reset each time. Explicit filesystem outputs remain on disk.

Only one program runs at a time. Stop sends a termination signal and escalates if the process does not exit after two seconds. Output is buffered by the runtime until execution finishes, so stopping can lose buffered output.

Reading the result

  • Completed: the process exited successfully. This does not establish equivalence to SAS Institute software.
  • Program error: inspect Diagnostics for an input or program error.
  • Runtime gap or defect: an unsupported feature or runtime problem was reported.
  • Cancelled: the run was stopped.
  • Launch failure or crash: check the bundled runtime and the diagnostic text.

ABORT can explicitly return exit codes. Read the diagnostic text when interpreting a status.

Navigate to a diagnostic

Double-click an original-source line in Diagnostics or use Command-L. Navigation is allowed only while the originating buffer still matches the executed snapshot. Macro-expanded positions cannot be mapped directly to the original editor.

After a run, LocalStat selects Diagnostics for a failure, Output Data for supported formatted results, or Results otherwise. It keeps the current pane height. Expand Results or Command-2 gives results more room.
