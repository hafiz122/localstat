Getting started with LocalStat

LocalStat is a native Mac editor for running a supported subset of the SAS language locally. It bundles an OpenSAS runtime and works offline. It is independent of SAS Institute software.

  1. Choose File > New Program or open a .sas file.
  2. Enter the program below, or choose Open Example in this Help window.
  3. Press Command-R to run the entire editor buffer.
  4. Read the Output, Tables, and Diagnostics views below the editor.
  5. Press Command-S to save your program.
data measurements;
  input value;
  datalines;
10
20
30
;
run;
proc means data=measurements n mean;
  var value;
run;

The result has three observations and a mean of 20. Open Example creates a new unsaved tab. It does not run the program automatically.

Know what a run means

Every run starts a fresh process. WORK datasets and macro state from an earlier run are not retained. Include all required steps in the program. Programs can read and write files allowed to your account, so run code and projects you trust.
