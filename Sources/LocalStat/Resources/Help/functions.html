Functions, dates, and formats

Functions return values inside expressions. CALL routines can update arguments or runtime state. The complete index distinguishes implemented entries from partial or unavailable ones.

Common groups

  • Numeric: ABS, ROUND, SQRT, LOG, EXP, MOD, and arithmetic/statistical functions.
  • Character: STRIP, UPCASE, LOWCASE, SUBSTR, SCAN, CATS, and CATX.
  • Missing values: MISSING, NMISS, CMISS, COALESCE, and COALESCEC.
  • Dates: MDY, DAY, MONTH, YEAR, INTCK, INTNX, and supported date/time functions.
  • Probability: CDF, PDF, QUANTILE, distribution functions, and random-number routines with supported parameters.

SAS-style dates count days from 1 January 1960; datetimes count seconds. A numeric format changes presentation, not the stored value. INPUT converts character data using an informat; PUT creates formatted character output. FORMAT attaches presentation metadata.

data demo;
  length name $20;
  name=upcase(strip('  Ana  '));
  magnitude=abs(-3);
  date=mdy(1,15,2026);
  format date date9.;
run;
proc print data=demo; run;

Supported signatures, missing values, encodings, and numerical edge cases can differ from the original SAS engine. Use a small known example when depending on a specialized function. An indexed name does not imply universal support for related operating-system, catalog, database, or external-service behavior.
