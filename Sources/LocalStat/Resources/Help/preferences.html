Settings and viewing controls

Open LocalStat > Settings with Command-comma. Changes apply immediately and are saved for the next launch.

Appearance

SAS Native is the default workspace appearance and editor palette. It uses a blue header, light Project Explorer, compact program tabs, and white code and results surfaces. System follows your Mac; Light and Dark use Mac controls. The toolbar selector and Settings stay synchronized. Native editor colors follow the chosen app appearance. Other editor palettes set code colors independently.

Editor and output fonts

Choose an installed monospace font and a size from 8 to 40 points. Editor and output/diagnostics have separate choices. If a saved font is unavailable, LocalStat uses the system monospace font. Highlighting preserves the chosen font after editing and theme changes.

Choose View > Editor Font… to open the Editor font controls directly. Choose View > Output Font… for the output and diagnostics font. These commands reuse the Settings window and focus the appropriate font chooser. You can also open Settings with Command-comma and select Editor or Output and Tables.

Editor controls include line spacing, word wrap, line numbers, syntax highlighting, visible whitespace, and current-line highlighting. Output wrapping is separate because wrapping can disturb the visual alignment of plain-text tables.

Sizes and layout

Increase, Decrease, and Reset Size in View follow the focused content. Table zoom ranges from 50% to 200%. Help has its own reading-size chooser. Drag pane dividers to resize them. Command-0 toggles the navigator; Command-2 expands or restores results.

Each Settings section has a reset button. Restore Default Layout returns to a 235-point navigator and an approximately 70/30 editor/results split. It does not change fonts, appearance, project selection, or program text.

Editing preferences

Choose 2, 4, or 8 spaces per indentation level; the default is 4. On upgrade, saved two-space settings switch to four once. Later explicit choices are preserved. Automatic indentation and bracket pairing can be turned off independently. These settings affect future edits and do not reformat existing source. See Editing SAS programs.
