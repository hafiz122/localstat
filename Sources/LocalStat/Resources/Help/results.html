Results, printing, and exports

Output shows the latest runtime listing. Tab-separated listing columns are aligned for reading. Export Last Run as Text preserves raw output and diagnostics rather than the display padding.

Formatted tables

Tables displays formatted PROC PRINT, PROC FREQ TABLES/NLEVELS, and PROC TABULATE output. Other procedures use the text Output view. Wide tables can continue across pages; headings repeat on later pages. Empty or unsupported table results show an explanatory message.

Settings > Output and Tables controls the output font and table zoom. Zoom changes the on-screen view without changing the underlying numbers, page layout, printing, or PDF reports.

Print and export

  • Print Tables prints all formatted tables from the latest run through the Mac print dialog.
  • Export Last Run as Text saves status, raw diagnostics, and raw text output.
  • Export Report as PDF creates a searchable report with the executed source snapshot, working directory, versions, status, tables, and raw-output appendix.

Exports describe the last executed snapshot even if you later edit the source. Keep that distinction in mind when sharing reports. LocalStat PDF export is an IDE feature, not an ODS PDF destination.
