Editing SAS programs

The source editor supports native Find, selection, copy, paste, and Undo. Command-F opens Find for the active text view. Text is saved as UTF-8.

Indentation

Tab inserts the configured number of spaces or indents selected lines. Shift-Tab removes one level. With automatic indentation enabled, Return preserves leading whitespace and adds a level after DATA, PROC, DO, SELECT, or an opening bracket. END, RUN, and QUIT reduce the following indentation.

Indentation is a heuristic, not a full parser or formatter. Changing indentation width affects later edits and does not rewrite your program. Disable automatic indentation in Settings > Editing to insert a plain newline.

Bracket assistance

Typing an opening parenthesis, square bracket, or brace inserts its closing partner. Selected text is wrapped. Typing an existing closing partner skips over it. Backspace between an empty pair removes both. These actions are suppressed inside strings, comments, and DATALINES text. Disable bracket pairing to turn off all four behaviors.

Reading code

Settings > Editor controls the font, size, spacing, wrapping, line numbers, whitespace marks, syntax colors, and current-line highlight. Wrapped continuations do not create new source line numbers. Syntax colors help reading but are not a syntax validator.
