Projects and files

A project is a folder used as the working directory for your program. Choose Open Project to change it. The project navigator shows folders and SAS programs in a tree. Expand a folder to see its contents, or double-click a program to open it. The four buttons under the project name add an existing folder, add an existing SAS file, create a SAS file, and create a folder. They use the selected folder, or the parent of a selected file. Added items are copied into the project. Use File > Refresh Project after changing files outside the app.

Opening and saving

File > Open Program opens files independently of the project folder. Each file has its own editor tab. An unsaved change is marked with an asterisk in the tab. Save As chooses another destination. Closing an edited tab asks whether to save, discard, or cancel.

Click the × button on a tab to close that program, or press Command-W to close the active program. Closing another tab keeps your current program selected. Tabs scroll horizontally when more programs are open than fit across the editor; selecting a program brings its tab into view. Long filenames are shortened in the tab, with the full path available in its tooltip.

Closing a source tab does not stop its running program or remove its last results. Diagnostic navigation is unavailable after the originating source tab is closed.

Running uses the current buffer, including unsaved edits. Saving the file is not required before running. Changing the project changes the working directory used by subsequent runs, including programs already open.

Relative paths

Relative filenames in %include, CSV imports, and other file operations resolve from the project folder, not necessarily from the source file's folder. Use the project label's tooltip to inspect its full path.

Examples and navigator

The Project Explorer starts with an empty Workspace folder. Bundled examples are copied separately to your user Application Support/LocalStat/Examples folder, so they do not fill the Explorer by default. Choose Open Example in Help to open an unsaved copy, or open the Examples folder as a project to browse and edit its files. Command-0 shows or hides the navigator. Drag its divider to resize it. File > Refresh Project updates the file list after changes made outside the app.
