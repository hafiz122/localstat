Projects and files

A project is a folder used as the working directory for your program. Choose Open Project to change it. The project navigator lists SAS files below that folder. Double-click a file to open it.

Opening and saving

File > Open Program opens files independently of the project folder. Each file has its own editor tab. An unsaved change is marked with a dot in the tab. Save As chooses another destination. Closing an edited tab asks whether to save, discard, or cancel.

Running uses the current buffer, including unsaved edits. Saving the file is not required before running. Changing the project changes the working directory used by subsequent runs, including programs already open.

Relative paths

Relative filenames in %include, CSV imports, and other file operations resolve from the project folder, not necessarily from the source file's folder. Use the project label's tooltip to inspect its full path.

Examples and navigator

On first launch, examples are copied to your user Application Support folder. You can edit those copies. Command-0 shows or hides the navigator. Drag its divider to resize it. File > Refresh Project updates the file list after changes made outside the app.
