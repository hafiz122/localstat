Reporting and statistics

A PROC step uses an existing dataset. Procedure names in the index indicate implemented subsets, not support for every option.

PRINT

proc print data=scores; var name score; run; lists observations. Supported options and statements include common NOOBS, LABEL, VAR, ID, SUM, and BY forms. It produces formatted Tables results as well as text output.

MEANS and SUMMARY

proc means data=scores n mean min max; var score; run; summarizes numeric data. SUMMARY belongs to the same family. Statistic keywords, grouping, output datasets, and weights have supported subsets. Results appear in Output.

FREQ

proc freq data=scores; tables group; run; counts categories. TABLES accepts supported one-way and cross-tabulation forms. NLEVELS reports levels. FREQ produces formatted Tables for the supported result forms.

TABULATE

proc tabulate data=scores; class group; var score; table group, score*mean; run; combines classifications and statistics. Its table-expression grammar and denominator/percentage options are limited. Unsupported forms should be read through Diagnostics. Supported tables also appear in Tables.

Data management

SORT orders observations; TRANSPOSE reshapes supported data; CONTENTS describes columns; DATASETS, APPEND, DELETE, and COMPARE provide supported management operations. FORMAT defines supported formats. REPORT, UNIVARIATE, RANK, IMPORT, EXPORT, and SQL have their own subsets.
