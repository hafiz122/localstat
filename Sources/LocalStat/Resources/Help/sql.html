SQL queries

PROC SQL provides a subset for querying and manipulating datasets. Finish the procedure with QUIT. Start with simple projections, filters, ordering, grouping, and supported joins before porting a large query.

data sales;
  input group $ amount;
  datalines;
A 10
A 20
B 7
;
run;
proc sql;
  select group, sum(amount) as total
  from sales
  group by group
  order by group;
quit;

The expected totals are A=30 and B=7. SQL output currently appears in the text Output view. SQL syntax, aggregate behavior, supported expressions, and dataset options have boundaries inherited from the local runtime. A successful query is not a guarantee of identical behavior to every SAS SQL feature.
