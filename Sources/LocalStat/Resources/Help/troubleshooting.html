Troubleshooting

A program worked in SAS but fails here

LocalStat implements a subset. Check the reported statement or option against compatibility and the reference index. Reduce the program to a small example. An indexed procedure or function may still have unsupported options or edge cases.

A dataset disappeared

Each run starts fresh. Create WORK datasets in the same buffer before using them. Use explicit file output for data that must persist, and confirm which project folder is the working directory.

A relative filename cannot be found

Open the intended project folder, inspect its full path through the project label, and check spelling and permissions. Relative paths use that project folder.

No output appears while running

The runtime buffers output. Wait for completion or stop the program if it is taking too long. Cancellation can lose buffered output. Large listings consume memory; filter the data or print fewer rows.

Output Data is empty

Only PRINT, FREQ TABLES/NLEVELS, and TABULATE produce formatted table results. Other procedures appear in Results. Some options suppress output. Inspect Diagnostics if a run failed partway through.

Diagnostic navigation is unavailable

The buffer may have changed or closed since the run, or the position may refer to macro-expanded source. Run the current source again, or inspect the reported line manually.

Text or panels are hard to read

Change fonts, sizes, theme, and wrapping in Settings. Restore the relevant section's defaults or Restore Default Layout. Display changes do not modify saved source.
