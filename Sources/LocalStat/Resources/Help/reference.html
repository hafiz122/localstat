Procedure and function index

This index covers the pinned local runtime. An implemented name is a supported subset, not a claim of complete SAS equivalence. Unavailable names are included so searches explain the boundary. The guide provides worked examples; this index does not reproduce the full SAS function dictionary.

SUMMARY shares the MEANS family. Additional runtime names and aliases are included below. The DATA-step SYSGET function is unavailable; the separate macro directive %SYSGET can read inherited environment variables. See Compatibility and limitations.
