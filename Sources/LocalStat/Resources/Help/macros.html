Macros and includes

Macro processing builds SAS source before or during step execution. Use %LET for a macro variable and an ampersand to substitute it. A macro can accept parameters and emit repeated code.

%let count=3;
%macro make(name);
data &name;
  do i=1 to &count;
    square=i*i;
    output;
  end;
run;
%mend;
%make(squares);
proc print data=squares; run;

The inherited subset includes nested definitions, positional and keyword parameters, local and global variables, conditional and loop directives, %EVAL, %SYSEVALF, %SYSFUNC, and parts of macro quoting. Quoting and deferred expansion have limits; a macro accepted elsewhere may require changes.

Include files

%include 'shared code.sas'; reads a source file using the current project directory for relative paths. Macro definitions from earlier LocalStat runs do not persist. Include or define everything needed in the submitted buffer.

CALL SYMPUT and SYMPUTX

These routines communicate DATA-step values to macro variables at step boundaries. Substituting a macro variable before it has been created can produce unexpected source. Inspect Diagnostics and keep the distinction between macro-time text and DATA-step values clear.
