# Workspace direction

LocalStat opens in the SAS Native appearance by default. [SAS Studio](https://documentation.sas.com/api/collections/webeditorcdc/v_045/docsets/webeditora11y/content/webeditora11y.pdf) provides the left navigation pane, tabbed program work area, and separate results conventions. The [Eclipse workbench](https://help.eclipse.org/latest/topic/org.eclipse.platform.doc.user/concepts/concepts-6.htm) informs the Project Explorer, editor tabs, contextual pane commands, and bottom results stack. LocalStat remains an independent AppKit application with its own name and supported actions.

A restrained blue application bar identifies the workspace. The folder tree, code, output, and tables use white reading surfaces. Pale gray toolbars and separators distinguish controls from content. Blue marks the active tab, primary Run action, and tree icons. Source uses a light syntax palette by default. System, Light, and Dark appearances and separate editor themes remain available as explicit choices.

The source editor occupies the main area. The Project Explorer locates programs; compact tabs mark the active program and unsaved edits. A contextual toolbar places Run and Stop beside the active program. The lower results area keeps output, formatted tables, and diagnostics close to the source. Resizable splits let the user prioritize reading code or output. Native controls keep keyboard behavior and accessibility.

Screen tables use a restrained blue heading treatment inspired by SAS Studio HTML output. Printed and PDF tables use white paper, centered titles and section headings, horizontal rules without vertical grid lines, and right-aligned numbers. This is a presentation convention for supported PRINT, FREQ, and TABULATE output, not an exact implementation of SAS ODS. [SAS ODS documentation](https://documentation.sas.com/api/collections/pgmsascdc/v_049/docsets/odsug/content/odsug.pdf?locale=en) describes the reference styles.

Energy 1, rhythm 1, motion 1: a document tool with hierarchy provided by source, diagnostic severity, and current execution state. No decorative motion or unrelated visual assets.
