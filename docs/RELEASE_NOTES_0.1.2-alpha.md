# LocalStat 0.1.2-alpha

This developer preview opens in the SAS Native appearance on a fresh install
or after resetting Appearance settings. The Project Explorer, compact program
tabs, contextual Run toolbar, editor gutter, settings, and results pane now
share a modern workbench layout. An asterisk marks unsaved programs. Existing
explicit appearance choices remain saved, including System, Light, and Dark.

Supported PRINT, FREQ, and TABULATE results use restrained blue headers on
screen. Table printing and PDF pages use white paper, centered titles and
narrow tables, horizontal rules, and right-aligned numeric values. This is a
SAS-inspired presentation for LocalStat's supported subset, not an exact SAS
ODS implementation.

The app is ARM64-only, ad-hoc signed, and not notarized. It is not a complete
SAS implementation and is not affiliated with SAS Institute. Run only trusted
programs and project folders: programs have the app's file access and inherit
its environment. See `docs/INSTALL.md`, `docs/COMPATIBILITY.md`, and
`docs/VERIFICATION.md` for installation, coverage, and validation details.

The owner has confirmed permission for the Patrick Jane photographic logo;
the grant reference and attribution details remain outstanding in
`ASSET_LICENSES.md`. A second physical Mac installation test remains
outstanding. The release archive includes its SHA-256 checksum and records the
source commit and verification results.
